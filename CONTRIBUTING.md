# Contributing

Bug reports and focused pull requests are welcome. Include your macOS version, CPU architecture, steps to reproduce, expected result, and actual result. Use a synthetic or redacted PDF; do not upload private documents.

Build with `python3 build_app.py` and run `python3 Tests/smoke_test.py` before submitting. For UI changes, also launch with a sample PDF and check thumbnail selection, typed ranges, multiple-file switching, folder export, and collision handling. Keep the native helper behavior and update both READMEs for user-visible changes.
