# Changelog

## 1.0.0 — 2026-10-04

Initial public release of the existing PDF Page Extractor helper.

- Native PDF preview, thumbnail multi-selection, and page-range input.
- Multiple PDF inputs and 200 DPI PNG export.
- Optional output folder and automatic output-name collision handling.
- Portable source build, English and Simplified Chinese documentation, and macOS CI.
- Diagnostic file-path logging is now opt-in.
